Cálculo de Engranajes

Modulo = Altura de la cabeza del diente
Altura del pie del diente = 1.167 x Modulo
= 1.167 x
Altura total del diente = 2.167 x Modulo
= 2.167 x
Radio del pie del diente = 0.3 x Modulo
= 0.3 x
Paso = Espacio entre dientes + Espesor del diente
= +
Espacio entre dientes = 0.5 x Paso
= 0.5 x
Espesor del diente = 0.5 x Paso
= 0.5 x
Paso circunferencial = Pi x Modulo
= Pi x
Paso diametral = 25.4 / Modulo
= 25.4 /
Diametro primitivo = Modulo x Numero de dientes
= x
Diametro primitivo = (Paso / Pi) x Numero de dientes
= ( / Pi) x
Diametro exterior = Diametro primitivo + 2 x Modulo
= + 2 x
Diametro exterior = Modulo x (Numero de dientes + 2)
= x (+2)
Diametro interior = Diametro primitivo - 2.5 x Modulo
= - 2.5 x
